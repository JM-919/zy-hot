# ZY热点

一句话：把全网热榜塞进一个页面，纯静态、零后端、零构建，扔到哪都能跑。

## 为什么做这个

想知道今天有什么热闹，本来得挨个开 App：微博看一眼、知乎看一眼、B站再翻一眼。
索性做一个页面，28 个平台一屏铺开，五分钟自动刷一次，看完就关。

## 怎么用

直接用浏览器打开 `index.html` 就能跑——本地双击也行，只有少数需要跨域的源会拿不到数据，挂到静态托管上就都正常了。

* 顶部五个分类页签：综合热搜 / 科技开发 / 海外视野 / 新闻资讯 / 影音娱乐，点一下只看这一类
* 搜索框输入关键词，所有榜单里不匹配的行自动隐藏，顺带告诉你「匹配 N 条」
* 每张卡右上角单独刷新；默认只露前 10 条，想看完点「展开全部」
* 右上角图标切深浅主题，选择记在 localStorage，跟系统走也行
* 页面左上角有时钟和本页运行时长，切回已过期的页面会自动补刷一次

## 里面有什么

| 文件 | 干什么的 |
| --- | --- |
| `index.html` | 页面骨架，包含首屏防闪烁的主题预渲染脚本 |
| `sources.js` | **平台清单**，想加平台、删平台、改分类，只动这一个文件 |
| `app.js` | 取数、渲染、搜索、主题、自动刷新 |
| `hot.css` | 样式，两套主题变量 + 卡片/榜单/响应式 |
| `.nojekyll` | 静态托管用，告诉托管方别拿 Jekyll 处理这些文件 |

## 几个实现上的选择

**没有后端。** 数据全部由浏览器直连各平台公开接口（主力是 codelife 的聚合接口，自带 CORS），省掉服务器也省掉成本，代价是受各家接口限流影响。

**每张卡互相独立。** 一张卡失败自动重试两次，再失败就自己显示重试按钮，绝不会拖累整页——这是刻意做的，因为聚合页最容易死在「一个源挂了整页白」上。

**主题不闪白。** 首屏在 `<head>` 里就把 localStorage 里的选择写成内联样式，而不是等 JS 跑完再切，所以深色模式用户不会先看到一帧白屏。

**搜索和折叠都在本地。** 不发请求，纯 DOM 过滤，输入即响应。

## 说明

数据来自各平台公开接口，仅供自己看看热闹，内容和准确性以原平台为准。
