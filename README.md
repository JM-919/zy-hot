# 今日热榜 · 全网热点实时聚合

一个**纯静态、零后端、零构建**的热榜聚合页：28 个平台 / 5 大分类 / 深浅双主题，每 5 分钟自动刷新。

> 在线地址：**https://jm-919.github.io/zy-hot/**

## 有什么

* **28 个平台**：微博 / 知乎 / 百度 / 头条 / 微信热文 / 什么值得买 / 贴吧 · GitHub / 掘金 / 少数派 / IT之家 / 36氪 / CSDN / 站酷 · Hacker News / dev.to / Product Hunt / App Store · 腾讯新闻 / 新浪财经 / 第一财经 / 雪球 · B站 / 抖音 / 豆瓣电影 / 虎扑 / 微信读书 / 懂球帝
* **5 大分类页签**：综合热搜 / 科技开发 / 海外视野 / 新闻资讯 / 影音娱乐，点一下只看这一类
* **搜索过滤**：输入关键词，所有榜单里命中不了的行自动隐藏，并给出「匹配 N 条」
* **深浅双主题**：跟随系统，也能手动切换，选择记在 localStorage（首屏内联脚本预渲染，不闪白）
* **每张卡独立**：单独刷新、加载失败单独重试（自动重试 2 次），一张卡挂了不影响其它
* **折叠 / 展开**：默认显示前 10 条，「展开全部（共 N 条）」看整榜
* **实时细节**：时钟、本页运行时长、加载耗时；回到页面若已过期会自动补一次刷新

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架（含防闪烁的主题预渲染脚本） |
| `sources.js` | **平台清单**：想加/减平台只改这一个文件 |
| `app.js` | 取数、渲染、搜索、主题、自动刷新 |
| `hot.css` | 样式（两套主题变量 + 卡片/榜单/响应式） |

## 数据来源

* 主力源：[codelife](https://api.codelife.cc) 聚合接口（自带 CORS，浏览器可直连）
* 官方接口：Hacker News（Algolia）、dev.to —— 两者都带 CORS
* 所有请求都是**浏览器直连**，本项目不经过任何自建服务器；某个源挂了只是那一张卡显示「加载失败」+ 重试按钮

## 本地跑

```bash
# 任意静态服务器都行（不能直接双击 index.html，否则 file:// 下有些浏览器会拦 fetch）
python3 -m http.server 8899
# 然后开 http://127.0.0.1:8899/
```

## 加一个平台

改 `sources.js` 往 `HOT_SOURCES` 里加一行即可（`cid` 是 codelife 的榜单 ID；也可以写 `api:'hn'` / `api:'devto'` 走官方接口）：

```js
{ id:'xxx', cat:'hot', name:'某平台', char:'某', color:'#e8442e',
  sub:'一句话简介', home:'https://...', cid:'榜单ID' },
```
